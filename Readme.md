# ResearchOS: Multi-AI Research Aggregation Platform

**Version:** 1.0.0
**Author:** Manus AI

## 1.0 Overview

**ResearchOS** is a "fire-and-forget" deep research platform designed to automate the gathering, synthesis, and reporting of complex information. It serves as a unified orchestration layer that sits on top of the world's most powerful AI research agents—**OpenAI Deep Research**, **Google Gemini**, **Anthropic Claude**, and **Manus**.

Instead of manually juggling multiple browser tabs, logging into different services, and copy-pasting results into a document, ResearchOS allows you to:
1.  Submit a single research query.
2.  Have it automatically refined by a strategist AI.
3.  Dispatch it in parallel to multiple research agents.
4.  Receive a single, consolidated, citation-backed report in your Obsidian vault or email inbox.

This application is built to run **locally** on your machine, ensuring it has secure access to your personal accounts (via browser automation) and your local file system (for Obsidian integration).

## 2.0 Architecture

The application follows a modern client-server architecture:

### 2.1 Frontend (Client)
- **Framework:** React 19 + Vite
- **Styling:** TailwindCSS v4 (Custom "Digital Zen" Design System)
- **Role:** Provides the user interface for submitting requests, tracking live progress, and viewing results.

### 2.2 Backend (Server)
- **Runtime:** Node.js + Express
- **Database:** Supabase (PostgreSQL) for persistent storage of history and settings.
- **Orchestration:** Custom TypeScript modules (`ai-services.ts`) manage the API calls to OpenAI, Gemini, and Claude.
- **Automation:** A **Playwright** script (`manus-automation.ts`) launches a local Chrome instance to automate the Manus web interface, bridging the gap where no public API exists.

### 2.3 Data Flow
1.  **User** submits a raw prompt via the Frontend.
2.  **Backend** uses a fast LLM (GPT-4o-mini) to refine the prompt into a research plan.
3.  **User** approves the plan.
4.  **Backend** spawns parallel tasks:
    *   Calls OpenAI/Gemini/Claude APIs directly.
    *   Launches a visible Chrome window to drive Manus.im.
5.  **Backend** collects all results as they finish.
6.  **Backend** uses a large-context model (Claude 3.5 Sonnet) to consolidate the findings into a single Markdown report.
7.  **System** delivers the report to Supabase, Obsidian (local file write), and/or Email.

## 3.0 Prerequisites

Before running ResearchOS, ensure you have the following:

1.  **Node.js:** Version 18 or higher.
2.  **Supabase Account:** A free project at [supabase.com](https://supabase.com).
3.  **API Keys:**
    *   OpenAI API Key
    *   Anthropic API Key
    *   Google Gemini API Key
4.  **Manus Account:** An active account at [manus.im](https://manus.im).

## 4.0 Installation & Setup

### 4.1 Clone & Install
```bash
# Unzip the package
tar -xzf research-platform-prototype.tar.gz
cd research-platform-prototype

# Install dependencies
pnpm install
```

### 4.2 Database Setup
1.  Log in to your Supabase Dashboard.
2.  Go to the **SQL Editor**.
3.  Open the `supabase_schema.sql` file included in this package.
4.  Copy and paste the SQL content into the editor and click **Run**. This creates all necessary tables and security policies.

### 4.3 Environment Configuration
1.  Rename `.env.example` to `.env`.
2.  Fill in your Supabase credentials (found in Project Settings > API):
    ```env
    SUPABASE_URL=https://your-project.supabase.co
    SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
    ```

## 5.0 Running the Application

You need to run both the backend server and the frontend client.

### Terminal 1: Backend
```bash
pnpm run server
# Server will start on http://localhost:3001
```

### Terminal 2: Frontend
```bash
pnpm run dev
# Client will start on http://localhost:5173
```

Open your browser to `http://localhost:5173` to begin.

## 6.0 Usage Guide

### 6.1 Initial Configuration
1.  Navigate to the **Settings** page.
2.  Enter your API Keys for OpenAI, Anthropic, and Gemini.
3.  (Optional) Enter the absolute path to your local Obsidian Vault.
4.  Click **Save**.

### 6.2 Starting Research
1.  Go to **New Research**.
2.  Type your question (e.g., "Future of solid-state batteries").
3.  Review the **Refined Plan** generated by the AI. Edit it if necessary.
4.  Click **Start Research**.

### 6.3 Monitoring Progress
- The **Progress** page will show live status cards for each agent.
- **Note:** For Manus, a separate Chrome window will pop up. **Do not close this window.** If you are not logged in, log in manually in that window. The script will take over once logged in.

### 6.4 Viewing Results
- Once all agents finish, the **Results** page will show the Consolidated Report.
- You can toggle tabs to see the raw output from individual agents.
- Use the **Email** or **Download** buttons to export the report.

## 7.0 Troubleshooting

- **Manus Automation Stuck:** If the Manus browser window opens but does nothing, ensure you are logged in. The script waits for the URL to contain `/app`.
- **Database Errors:** Check your `.env` file to ensure `SUPABASE_URL` and `KEY` are correct.
- **API Errors:** Verify your API keys in the Settings page. Ensure you have credits/quota available on your AI provider accounts.
